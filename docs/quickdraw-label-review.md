# Quick, Draw! 라벨 검토

전체 목록은 `data/quickdraw/metadata/labels.json`, 그림 예시는 `data/quickdraw/previews/index.html`이다.
공식 영문 클래스 345개는 모두 유지하며, 숫자 클래스 ID와 한국어 표시명은 프로젝트가 관리한다.

## 서비스 기획과 연결

데이터는 그림 분류용이다. 카테고리 사이의 의미 유사도나 색·형태·용도 속성은 제공하지 않는다.
그림 분류 모델을 학습하는 데이터와 숨겨진 대상 속성으로 유사도를 만드는 데이터는 별도로 준비해야 한다.
`labels.json`에는 후속 속성 주석을 위한 빈 `attribute_tags`와 `attribute_status=not_annotated`를 둔다.
이 빈 값을 '모든 속성이 없음'으로 해석해서는 안 된다.

18개 대분류는 목록 검토를 위한 초안이다. 예를 들어 비행기와 새는 다른 대분류지만 '비행/날개/하늘'을 공유할 수 있고,
버섯은 식물이 아니므로 편의상 `plant_fungus` 그룹으로 관리한다. 대분류 하나만으로 유사도를 계산하면 안 된다.

## 정답에서 제외 제안: 13개

- 동작·추상: `animal migration`, `camouflage`, `yoga`.
- 기하·기호: `circle`, `hexagon`, `line`, `octagon`, `smiley face`, `square`, `squiggle`, `star`, `triangle`, `zigzag`.

구체적인 대상을 그리는 현재 서비스 의도를 기준으로 한 **제안**이다. 학습 데이터에는 전부 포함된다.
별 모양 같은 항목도 플레이 정책에 따라 재포함할 수 있다. 이 결정은 데이터셋 자체의 품질 평가가 아니다.

## 우선 검토: 18개

| 라벨 | 검토 이유 |
|---|---|
| bird, fish | 넓은 범주와 개별 동물 범주가 함께 존재함 |
| cup, mug, coffee cup | 같은 한국어 이름과 비슷한 윤곽으로 겹치기 쉬움 |
| cake, birthday cake | 촛불 등 작은 차이로 클래스가 갈릴 수 있음 |
| clock, alarm clock | 시계·알람시계 표현 경계 |
| hurricane, tornado | 현상은 다르지만 단색 그림에서 혼동 가능 |
| diamond | 보석과 마름모 표현을 샘플로 확인할 필요 |
| stitches | 봉합 자국·바느질 표현 확인 필요 |
| fan | 부채와 전기 선풍기 해석 확인 필요 |
| spreadsheet | 문서/화면 개념이 정답 범위에 맞는지 결정 |
| The Eiffel Tower, The Great Wall of China, The Mona Lisa | 고유명사 출제 정책과 한국 사용자 인지도 검토 |

이 밖에도 `computer/laptop`, `telephone/cell phone`, `car/police car`, `bus/school bus`,
`bear/teddy-bear`, `beard/goatee/moustache` 등을 혼동 행렬에서 확인해야 한다.
18개 목록은 전수 품질 검수가 아니라 우선 검토 목록이다.

## 겹치는 개념 정리 결과

2026-09-23 [카테고리 정리 v1](catalog-curation-v1.md)로 처리했다.

- 검토 반영 버전 `catalog-curation-v1.1`은 하위 종류·부분 정답 인정 초안에 따라 10개를 대표 카테고리로 통합한다. 예: 머그잔·커피잔 → 컵. 부분 정답 인정 규칙은 출시 전 검증한다.
- 첼로–바이올린, 블랙베리–블루베리, 크레용–연필, 여권–책, 식기세척기–세탁기, 허리케인–토네이도는 통합을 보류하고 각각 유지한다.
- 넓은 상위 개념인 `bird`는 점수·정답에서 제외하지만 원래 확률과 인식 후보는 유지한다. Top-3에 포함되면 판정을 보류한다.
- 매핑 후 인식 후보는 335개, 점수 지원 초안은 334개, 데일리 후보는 323개다. 정답 제외 제안 13개 중 `star`, `smiley face`는 사용자 결정대로 정답 후보를 유지한다.
- 원본 345개 클래스와 순서는 유지한다.

## 미리보기 확인

초기 시각 확인에서 `cat`, `fan`, `diamond`의 첫 20장을 확인했다.
고양이의 얼굴·전신처럼 같은 라벨 안에서도 표현이 다양했고, `diamond`에는 보석 윤곽과 마름모가 섞여 있었다.
28×28 렌더링 결과는 확인했지만 전체 345,000장에 대한 사람 검수를 수행한 것은 아니다.
전체 라벨 미리보기에는 각 라벨의 첫 20장을 제공한다.

## 모델 학습 이후 결정할 사항

1. 실제 그림판 입력으로 라벨별 인식률·오인식·잘못된 성공을 평가한다.
2. 구분이 어려운 클래스는 데일리 정답에서 보류하거나 허용 범위를 명시한다.
3. 정답 후보별로 형태·기능·환경·물성 태그를 작성하고 가까운 후보가 납득되는지 확인한다.
4. 색·온도는 단색 스케치에서 직접 관측되는 값이 아니라 대상의 대표 속성일 수 있음을 구분한다.
5. 검증 전에는 `candidate_unvalidated`를 출시 승인 상태로 취급하지 않는다.
