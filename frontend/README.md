# 드로맨틀 게임 화면

React + TypeScript + Vite, 기본 Canvas 2D로 만든 한 페이지 게임 화면이다. 위에서부터 문제 안내 → 그림판·되돌리기/지우기/제출하기 → 성공 결과 → 제출 기록 → 질문과 답변 → 출처 순서이고, 모든 영역이 같은 폭(최대 560px)이다. 배치 기준은 [프론트 화면 계획](../docs/frontend-plan-v1.md)이다.

## 실행

Node 22.18 이상. 최초 `npm ci`, 개발 `npm run dev`(http://127.0.0.1:5173), 타입 확인과 배포 빌드 `npm run build`, 테스트 `npm test`.

개발 서버는 `/api`를 http://127.0.0.1:8000 의 FastAPI로 넘긴다. DB·백엔드·개발용 릴리스 준비는 [저장소 README의 로컬 실행](../README.md#로컬-실행)을 따른다. 해시 생성에는 secure context가 필요하다(localhost는 지원).

## 동작

- 획 좌표는 화면 크기와 독립인 0~1024 정수이고 펜은 논리 폭 8, 검은색이다. 제출 순간의 획을 동결해 고정 필드 순서 JSON의 SHA-256(`drawingHash`)과 192px 썸네일을 만든다.
- 서버로는 그림 원본을 보내지 않는다. 릴리스 버전, 그림 해시, Top-3(원래 p 그대로)만 보낸다. 점수·성공은 서버 응답을 그대로 표시하고 다시 계산하지 않는다.
- 제출 전에 요청 본문을 브라우저에 저장한다. 연결이 끊기거나 서버가 일시 오류를 내면 같은 제출 ID·본문으로만 다시 시도하며, 새로고침하면 먼저 요청 ID로 결과를 조회하고 없을 때만 같은 본문을 다시 보낸다. 확인 전에는 새 제출을 시작하지 않는다.
- 같은 그림을 다시 제출하면 서버가 기존 결과를 돌려주고 기록 행을 추가하지 않는다. 판정 보류는 점수·시도 번호 없이 안내만 한다.
- 기록은 맨 위에 직전 제출을 고정하고 그 아래에 모든 시도를 유사도 순으로 보여준다(10개씩 `기록 더 보기`, 번호는 서버 시도 번호). 최고·정답은 글자 표시를 함께 쓴다. 현재 획과 썸네일은 문제별로 이 브라우저에 저장되며 없으면 `미리보기 없음`으로 표시한다.
- 성공하면 결과 영역에 정답·성공한 그림·총 시도·최고 유사도를 보여주고 추가 제출을 막는다. 포기 기능과 예측 단어·순위 표시는 없다.

## 언어

오른쪽 위 `ENG`/`KOR` 버튼으로 모든 화면 문구를 한국어·영어로 바꾼다. 문구는 `shared/i18n/messages.ts` 한 곳에 있고, 영어 사전은 타입과 `tests/unit/i18n.test.ts`로 한국어와 같은 항목을 모두 갖추도록 검사한다. 제목은 한국어에서 `드로맨틀` + 작은 `drawmentle`, 영어에서 `Drawmentle` + 작은 `드로맨틀`이다. 선택은 이 브라우저에만 저장하고 기본은 한국어다. 서버 오류는 서버 문구 대신 오류 코드로 사전에서 찾는다. 카테고리 영어 이름은 릴리스 manifest의 `displayNameEn`을 쓰고, 영어 이름이 없는 이전 릴리스(`dev-release-v1`)는 ID를 읽기 쉬운 형태로 바꿔 보여준다(`hot_air_balloon` → `hot air balloon`).

## 개발용 인식 결과 패널

모델이 없는 개발용 릴리스(`inference.mode = dev_manual_top3`)에서만 보인다. `1위만 고르기`는 고른 후보에 p 0.7을 주고 2·3위(0.2/0.1)는 그림 해시로 정해 같은 그림이면 같은 Top-3가 된다. `세 후보와 p 직접 입력`은 세 후보와 p를 정하며 p 내림차순, 같으면 candidate_index 순으로 정렬해 보낸다. 운영 모델을 붙이면 이 패널 대신 `features/inference/modelRuntime.ts`가 같은 형식의 Top-3를 만든다.

## 파일

`features/drawing`은 획 입력·동결 사본·썸네일, `features/game`은 화면(`GamePage`)·상태(`useGame`)·제출 절차(`submissionFlow`)·기록·결과·Q&A·스타일, `features/inference`는 개발 패널, `shared/api/client.ts`는 HTTP, `shared/storage/gameStorage.ts`는 브라우저 저장을 맡는다.
