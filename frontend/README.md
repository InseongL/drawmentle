# 그림판 프로토타입

React + TypeScript + Vite, 기본 Canvas 2D로 만든 단일 페이지다. 그림판·그리기/Undo/Reset/제출·썸네일 기록·판정 요청 초안만 구현했다. 서버 요청, 분류 모델, 점수 계산, 학습용 수집, 영구 저장은 없다.

## 실행

Node 22.18 이상 권장. 최초 `npm ci`, 개발 `npm run dev`, 타입 확인과 배포 빌드 `npm run build`, 획/사본 규칙 확인 `npm test`.

기본 주소는 http://127.0.0.1:5173 이다. 개발 서버는 로컬 컴퓨터에서만 접속 가능하다. 모바일 실기기 연결과 HTTPS 설정은 별도 작업이며, 해시 생성에는 secure context가 필요하다(localhost는 지원).

## 동작과 범위

- 마우스·터치·펜의 기본 포인터 하나로 그린다. 입력 취소 시 진행 중인 획은 버린다. 단일 점도 한 획으로 저장한다.
- 좌표는 화면 크기와 독립인 0~1024 정수다. 프로토타입 펜은 논리 폭 8, 둥근 끝, 검은색이다. 화면/썸네일에 같은 렌더러를 사용한다.
- Undo는 마지막 획, Reset은 현재 획 전체만 제거한다. Reset 후 Undo로 이전 그림을 복원하지 않는다. 제출 기록은 유지한다.
- 제출 사본을 깊게 복사하고 동결한 뒤 고정 필드 순서 JSON의 SHA-256과 192px PNG 썸네일을 만든다. 연속 중복 좌표만 제거하며 임의 간소화나 획 잘라내기는 하지 않는다.
- 같은 해시를 재제출하면 기존 기록을 안내한다. 아직 서버 대표 ID는 없으며 데모 ID는 클라이언트 요청 ID다.
- API 초안의 top3/릴리스·모델 버전은 null이다. 이는 미연결 표시용으로, 실제 API의 유효한 요청이 아니다. 모델 확신도나 게임 점수를 꾸며내지 않는다.
- 원본 획은 일반 Top-3 판정 요청에 넣지 않는다. 데모에서는 내용을 따로 펼쳐 볼 수 있다.
- 새로고침하면 모든 기록이 사라진다. 저장 한도·모델 전처리·운영 펜 규격은 실제 모델 연결 전에 확정한다.

`drawingState.ts`는 좌표/불변 사본, `DrawingCanvas.tsx`는 입력/화면, `drawingSnapshot.ts`는 렌더링/해시/썸네일을 맡는다. `App.tsx`는 임시 데모 연결이며 실제 게임 API나 모델 런타임을 포함하지 않는다.
